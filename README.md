NEON VOID is a twin-stick arena shooter: survive 10 waves of void creatures, choose 1 of 3 upgrades between waves, and defeat the Void Core to win the sector. Six enemy types with their own behaviour, a boss every 5 waves, dash with invulnerability frames, combo scoring, pickups, and synthesized sound — plain canvas and vanilla JavaScript, no libraries, no network.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
